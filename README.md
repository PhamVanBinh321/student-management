This is a small WinForms application developed to manage student information, utilizing SQL Server for database management. The project includes the following features:

Student Management: Add, update, delete, and view student details (name, age, gender, class, etc.).
Search and Filter: Search for students by name, ID, or class, with advanced filtering options.
